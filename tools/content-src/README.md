Python source files used to write the reading and toolkit content (p1–p12 are the mission texts and questions, h.py/h2.py are helpers, merge_long.py assembles reading-long.json, quotecheck.py checks that quotes in answers appear in the texts, toolkit/ builds toolkit.json). They are kept for reference: the JSON files in /content are the source of truth, and `node tools/validate.mjs` is the check. Some scripts have paths from the original machine and may need small edits to run.
